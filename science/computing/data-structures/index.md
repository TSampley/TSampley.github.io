Data structures are specific arrangements of memory with associated semantics for the sake of different processing applications. They are both produced by and are critical to [algorithms](../algo/).

## Abstract Foundations
These abstract data structures can be implemented in a variety of ways, which determine their performance in practice, but they are the conceptual building blocks for all others.

### List
A list is a sequence

### Set
A set is a grouping of 0 or more elements, where each element is distinct. A set cannot contain multiple instances of the same element.

### Bag
A bag is similar to a set, but it permits multiple instances of elements.

### Map
A map associates a discrete set of keys with static values.

### Functions
A function can be seen as a generalization of a map that can return a value for any valid input. Functions can be stateful, potentially returning different values for the same input across invocations, or they can be stateless and return the same output for the same input every time.

### Object
An object is an abstraction of a set of functions with an associated map. In languages that support them ([object-oriented languages](../lingua/index#object-oriented)), they are usually constructed from classes that describe a layout of data, often called properties or fields,
