## Paradigms
Software development languages have gone through many phases experimenting with different paradigms, with parts of the fractured ecosystem developing and experimenting with the same ideas at different times.

### Procedural
The introduction of procedural programming allowed developers to group sequences of instructions into logical units of execution called procedures.

### Functional
Functional programs took procedural programming a step further by providing a scope local to the function for variables, separate from the global scope of purely-procedural languages.

### Object Oriented
Object-oriented programming, in effect, added intermediate scopes between the outer, global scope, and the inner, functional scope.
