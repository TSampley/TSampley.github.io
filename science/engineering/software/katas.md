Software development katas, like the martial arts exercise, are software exercises meant to let some practitioner apply techniques or explore an idea with a recognized form. Like software patterns, the following examples are meant to utilize a vocabulary over a common set of use cases, and, like myths, they're meant to provide familiar narratives to use as conceptual touchstones.
